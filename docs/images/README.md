# UI Screenshots

Place your interface screenshots in this folder. The main `README.md` references the following filenames — drop your PNG/JPG files in here using the same names and they will appear automatically.

## Required images

| File name              | Suggested content                                  |
| ---------------------- | -------------------------------------------------- |
| `banner.png`           | Project banner / hero image (1200 x 400 ideal)     |
| `login.png`            | Login screen                                       |
| `register.png`         | Registration screen                                |
| `dashboard.png`        | Dashboard / home page after login                  |
| `projects.png`         | Project list page                                  |
| `project-detail.png`   | Project detail view                                |
| `documents.png`        | Documents upload & list page                       |
| `analysis.png`         | Analysis page in progress                          |
| `analysis-result.png`  | Analysis result view                               |
| `reports.png`          | Reports list / report detail                       |
| `knowledge-base.png`   | Knowledge base search & QA                         |
| `chat.png`             | Chat / Q&A interface with agents                   |
| `admin.png`            | Admin panel (if applicable)                        |
| `architecture.png`     | System architecture diagram (optional)             |

## Tips

- Use **PNG** for UI screenshots (clearer text), **JPG** for photos.
- Keep widths around **1200–1600 px** for crisp display on GitHub.
- Crop unnecessary chrome (browser tabs, OS bars) so the UI is the focus.
- If you rename files, remember to update the paths in `../../README.md`.
